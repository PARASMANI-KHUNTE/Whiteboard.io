# Whiteboard.io Development Guidelines

## Complete Development Lifecycle

Always adhere to the following 10-step pattern for all tasks, bugs, and features:

1. **Create an Issue**
   - Document a bug, feature request, improvement, or task clearly.

2. **Assign and Plan the Task**
   - Add labels, priority, milestone, and assignee.

3. **Create a Branch**
   - Work independently without affecting the `main` branch (e.g. `feature/<name>`, `fix/<name>`).

4. **Develop and Commit**
   - Make small, meaningful commits with proper, descriptive commit messages.

5. **Push Your Branch**
   - Upload your branch and changes to GitHub.

6. **Create a Pull Request**
   - Explain what changed, why, and how you tested it.

7. **Code Review**
   - Reviewers inspect the code, request changes, or approve it.

8. **Automated CI/CD Checks**
   - Run tests, linting, builds, and other quality checks before merging.

9. **Merge the PR**
   - Merge after required approvals and successful checks.

10. **Release and Deploy**
    - Tag a release, generate release notes, and deploy if applicable.
